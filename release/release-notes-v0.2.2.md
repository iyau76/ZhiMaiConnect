# 知脉 Connect 0.2.2 · 关系演示与移动端修复

本版合并了两批主线改进（PR #3、PR #4），并修复移动端录入按钮被底部导航遮挡的问题。

- **关系演示与日期精度**：录入页新增「复杂关系测试集」选择器（桌面端），可一键载入多组合成关系材料；日历支持月精度日期，家谱拖拽覆盖更完整的亲属场景。
- **兼容修复**：从旧版本升级后，历史事件日期与家谱交互保持正常，配套回归测试覆盖。
- **移动端修复**：手机录入页的导入、拍照、录音按钮不再被底部导航栏遮挡。
- **版本**：桌面 0.2.2；Android 内部版本号从 2 升至 3。

## 从 0.2.1 升级

1. 在设置中导出 JSON 完整备份。
2. 退出旧版应用，运行新安装包覆盖安装；Android 无需先卸载，本版沿用同一测试签名。
3. 打开应用，检查原有资料。应用目前没有自动更新。

Windows 未配置发布者签名，Android 使用测试签名。首次安装时按系统提示核对来源并授权安装。
