# 知脉 Connect 0.3.3 · 录入文件不再固定卡在 8,000 字

这次只改一件事：**导入文件的文本上限不再写死 8,000 字，改为跟随你的 Agent 预算档位。**

- 生效上限 = `当前档位的输入 token × 0.8`，且不低于原来的 8,000 字。
  按当前档位：快速约 1.6 万、标准约 4.8 万、深度约 9.6 万字符（中文约 1 字 ≈ 1 token）。
- 录入页那行说明与「超出部分未发送」的提示都用**当前生效值**，不再固定显示 8,000。
- 单文件 ≤12 MB、PDF 最多 8 页、一次最多 4 个文件的限制不变；被截断时原文仍保留在输入框里。
- 副作用提醒：档位调得越高，单次录入送进上下文的材料越多，模型调用会更贵、更慢；档位本身没变。
