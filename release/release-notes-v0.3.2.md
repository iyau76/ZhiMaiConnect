# 知脉 Connect 0.3.2 · 关系网重做与检查更新

本版把人物关系网重做了一遍，并加上「检查更新」。关系网默认仍是原版布局，新版作为测试功能可切。

## 关系网

- **文字不再被缩成几个像素**：标签改成屏幕空间绘制，字号固定为 CSS 像素，缩放只改变名字之间的距离。
  原先世界坐标里 12px 的字，缩放到默认视图只剩 2.3px。
- **「适应」变成了真的适应内容**，缩放百分比以「刚好放满」为 100%，缩放锚点跟着指针。
- **新版布局（测试）**：一个人可以有多个圈层。新版把「一个人只属于一个组合」拆掉——
  圈层当集合，一个人同时落在多个圈层的外形里，交集处自然重叠；几何换成确定性两层布局
  （圈层锚点 + 人物松弛 + 连通分量打包），不再围成一个大圆环。工具栏右侧「原版 / 新版（测试）」切换，
  选择会记住，录入页预览跟着同一个开关。
- **包络经过校验**：画出来的范围严格等于「成员凸包 + 扩张半径」，成员节点一定在内、非成员一定在外；
  凸包会误包站在成员之间的人时，这一层拆成几段同色轮廓，而不是把人圈进「亲属圈」。
- **人多时自动分级**：51 人演示库默认只显示约一半名字（按圈层空间抽样，不看重要程度），
  放大后名字自动回来，选中与搜索命中的永远保留；圈层加编号徽标，标题放不下也能和图例对上号。
- 拖动只覆盖坐标，不再重跑整轮迭代；圈层配色改成固定色相表，不再撞色。

## 检查更新

设置 →「关于与更新」：显示当前版本与运行环境，点「检查新版本」读 GitHub Releases。
有新版按平台给安装包；已经最新会明确写出来；连不上 GitHub 时给原因并保留「打开发布页」手动下载。
预发布版本比同号正式版小，不会把正式版用户推去下载预览包。

## 演示库

本版一并合入演示库（DemoPack）重构：演示数据改成可插拔的包，生活场景与世界剧场共用一套装配器，
新增世界剧场插画与场景选择。详见仓库内 `doc/architecture/演示库DemoPack架构.md`。

## 从 0.3.1 升级

1. 在设置中导出 JSON 完整备份。
2. 覆盖安装新包（Windows 运行安装程序；Android 直接安装，沿用同一测试签名，versionCode 6 覆盖 5）。
3. 打开应用检查资料。安装版仍没有自动更新，但网页版可以用设置里的「检查新版本」对照发布页。

Windows 未配置发布者签名，Android 使用测试签名；首次安装按系统提示核对来源。
