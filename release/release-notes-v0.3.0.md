# 知脉 Connect 0.3.0 · 免费体验与评审修复

本版合并了 PR7 的评审修复，并新增内置的「知脉免费体验」档：**没配过任何密钥的用户，装上就能把「写一段话 → AI 整理 → 核对批准」走通**。

- **免费体验档**：新增档位，首次打开即为使用中，不可删除、地址不可改。不需要注册、不需要填 Key。
- **隐私说明同步更新**：首次调用前会弹确认框，写明数据会经知脉的体验服务器转发给模型服务商、只转发不保存内容、额度有限可能排队。免费额度不含语音转写。
- **录入页不再卡死**：原来「没配 API Key」只给一个页内提示，现在弹出对话框，三个出口——用免费体验试试（切换档位并自动重跑）、去配置自己的模型、展开三分钟配置指引（附智谱 / DeepSeek / Moonshot 平台网址）。
- **评审修复**：日历保存具备提交生命周期与冲突检查、录入撤销保留你在提交之后做的手工编辑、关系面板与人物卡补齐头像、移动端录入按钮不再被底部导航遮挡、身份匹配与日期解析加固。
- **版本**：桌面 0.3.0；Android 内部版本号从 3 升至 4。

2. 退出旧版应用，运行新安装包覆盖安装；Android 无需先卸载，本版沿用同一测试签名。

Windows 未配置发布者签名，Android 使用测试签名。首次安装时按系统提示核对来源并授权安装。

## 关于免费体验档

它由知脉提供的服务器转发，使用的上游模型与你自己配 DeepSeek 时是同一个，所以**质量不打折**。两条路的差别只在数据路径：免费档会经过我们的服务器（只转发、不记录），自己配 Key 则是设备直连模型服务商。介意的话，在「AI 助理」页把配置换成自己的即可，免费档随时可以不用。
