# 知脉 Connect 0.3.1 · 手机端数据集与英文界面修复

本版修掉两个你实测发现的问题，都是 0.3.0 里就有的。

- **手机上现在能看到虚拟数据集了**：录入页那块的样式写成了 `hidden md:block`，768px 以下的屏幕整块不显示——也就是手机上完全看不到红楼梦、三体这些可一键载入的测试材料。已移除断点限制，390px 视口实测可见。
- **英文界面补全**：0.3.0 的英文字典只有 1182 条，缺条目时会静默回退中文，所以界面是中英混排。本版补齐到 1421 条，覆盖「今天」页（标题、见面简报整块、日期）、「模型选择」页（接口类型名、内置预设名）、日历、关系网、提醒、录入核对等页面。
  - 日期原先跟随浏览器 locale，在中文系统上会让英文界面显示「9月18日星期五」，现在跟随应用语言。
  - 日历的农历标签没有合适的英文短形式，英文模式下不再显示，而不是在格子里印「廿一」。
  - 虚拟数据集的**内容**（作品名、受众描述、示例问题）保持中文——它们是中文文学的演示材料，材料正文本身也是中文。
- **版本**：桌面 0.3.1；Android 内部版本号从 4 升至 5。

## 从 0.3.0 升级

1. 在设置中导出 JSON 完整备份。
2. 退出旧版应用，运行新安装包覆盖安装；Android 无需先卸载，本版沿用同一测试签名（versionCode 5，可直接覆盖 versionCode 4）。
3. 打开应用，检查原有资料。应用目前没有自动更新。

Windows 未配置发布者签名，Android 使用测试签名。首次安装时按系统提示核对来源并授权安装。
