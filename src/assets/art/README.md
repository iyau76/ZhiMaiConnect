WebP 保持原图比例，质量 78。欢迎图宽 1280px，场景图宽 640px（4:3），空状态图宽 400px。界面标题和按钮继续用可翻译的 HTML；图片为装饰，使用空 alt，不参与人物、事件和日期的数据表达。

原稿 002、003、010—016 留作后续场景使用。添加素材时按实际展示尺寸导出，避免整组原图进入应用。世界剧场插画使用原创意象构图，不复刻任何现成作品的画面或官方美术。
