# 世界剧场 · 黑暗森林演示库设计说明

对应数据文件 `src/lib/demo-packs/world/santi.ts`，契约测试 `santi.test.ts`。
本库回答的问题是：一张横跨四个世纪的关系网，能否让「时间精度」成为演示的主角——同一份档案里既有精确到日的执剑人交接，也有只记得「危机纪元 205 年」的末日之战。

界面文案避免原著书名等商标词，库内显示名用「黑暗森林」；人物照用原著中文名，历史政治背景一律淡化，聚焦科幻主线与人物协作。

## 一、范围与口径

- 取材《三体》三部曲（《三体》《黑暗森林》《死神永生》）。人物 25 人，关系 37 条，事件 19 个，提醒 4 条，圈层 9 个。
- `egoKey` 为罗辑（`luoji`），亲密度（closeness 1-5）与提醒均为罗辑视角的演示设定；当前装配器按「无我」模式运行，该字段为角色扮演玩法预留。
- 联系方式口径是 `demo-<key>@example.invalid`；11 人留空（红岸时期人物、已故者、罗辑未曾谋面的远端人物）。
- 已故人物（杨冬、杨卫宁、雷志成、丁仪、泰勒、雷迪亚兹、章北海、东方延绪、叶文洁）保留档案以维系关系链，死亡事实保留、措辞从简。
- 关系 note 全部写明原著依据（37/37 带「原著」字样并注明部别）；不确定的一律不写——宁少勿错。

## 二、纪年映射（本库灵魂）

`LifeEventRecord.date` 是排序与定位用的公历近似，原著纪年原文一律保留在 `dateText`。映射口径自定如下，只保证先后顺序正确：

| 原著纪年 | 档案公历 | 依据 |
| --- | --- | --- |
| 红岸发射 1971 年秋 | 1971-09-01（year） | 原著第一部：叶文洁借太阳能量镜面发射，八年后收到回信 |
| 危机纪元 N 年 | 2006 + N | 危机纪元 2007–2214 共 208 年（百度百科「危机纪元」），元年取 2007 |
| 威慑纪元 N 年 | 2214 + N | 危机纪元 208 年罗辑建立威慑，威慑纪元共 62 年 |
| 广播纪元 N 年 | 2277 + N | 威慑终止后经威慑后纪元转入，取 2278 为元年 |
| 掩体纪元 N 年 | 2332 + N | 掩体纪元 2333–2400（三体系列时间线站） |

事件跨度从 1971（红岸发射）到 2398（蓝星重逢），共 19 个事件全部带 `dateText`。时间精度谱系：

- `year`：16 个（「1971 年秋」「危机纪元 205 年」等）；
- `range`：1 个（面壁计划启动，「危机纪元 3 年」）；
- `day`：2 个（执剑人交接「威慑纪元 62 年 11 月 18 日」、蓝星重逢「航程五十二小时」）——全库只有这两个时刻精确到日，反衬世纪尺度下多数记忆只剩年份。

## 三、八项契约特性的落点

1. 待确认关系：章北海 → 常伟思 knows（pending），「立场存疑（待确认）」——原著中常伟思始终未能完全确认章北海的失败主义倾向；同对人物另有一条已确认的 reports_to。
2. 已结束关系：11 条（叶文洁-杨冬 parent_of ended、丁仪-杨冬 custom「恋人」ended、罗辑-白蓉 custom「前女友」ended、红岸时期同事与婚姻、章北海-东方延绪「黑暗战役」止、程心 reports_to 维德止于掩体纪元 11 年等）。
3. 身份史：罗辑两段 identities——「面壁计划（模拟）」alias 面壁者（危机纪元 3 年起）、「黑暗森林威慑（模拟）」alias 执剑人（威慑纪元元年起）；云天明「阶梯计划（模拟）」alias 礼物（危机纪元 8 年起，呼应送星星与阶梯计划赋予他的身份）。
4. 联系方式有无：11 人留空（见口径一节），其余 14 人按域名口径填写。
5. 生日覆盖：19/25（≥半数）。**生日全部为合成填充，原著无任何人物生日设定**——这是本库对「演示数据可以虚构、事实注记必须诚实」的边界演示，note 与本说明双重标注；红岸时期与已故面壁者 6 人不填，档案叙事为「早期档案不全」。
6. 时间精度：见上节，19/19 事件带 dateText，其中 16 个 dateText 含「纪元」原文。
7. 提醒：4 条，due 全部落在 2026-09-20 ~ 2026-10-15（复核雪地工程巡检报告、回复 PDC 听证会质询函、和史强补一顿涮羊肉、为庄颜寻一册新画册），均为罗辑视角。
8. 连通性：以 luoji 为锚直径 3，全部 25 人可达。桥接链：罗辑—史强—汪淼—叶文洁—杨冬—丁仪（第一部人物经两跳进入罗辑一环）；罗辑—程心—云天明/艾AA/关一帆；罗辑—章北海—东方延绪。

## 四、关系设计的取舍

- 云天明 → 程心 `has_crush_on`（暗恋）：note 写明「大学时即暗恋；生命末段通过群星计划匿名买下恒星 DX3906 赠予她」；另配 classmate_of 大学同学（former）。
- 面壁者与破壁人：希恩斯-山杉惠子用规范谓词 spouse_of（partnerRole: husband），破壁人身份写进 note，不另设伪谓词；泰勒、雷迪亚兹的破壁人原著未具名，不入库。四位面壁者之间用 knows「面壁同僚」相连。
- 章北海 → 常伟思 reports_to（太空军，ended）+ knows pending（立场存疑）双条并存：一实一疑，分别演示已确认与待确认两种置信状态。
- 程心 reports_to 维德：危机纪元阶梯计划团队与掩体纪元星环集团两段共事，note 合并陈述，validity ended 止于掩体纪元 11 年（星环城事件）。
- 叶文洁 → 杨冬 parent_of（ended，措辞克制）；罗辑-庄颜 spouse_of；罗辑-白蓉 custom「前女友」——本体词表没有「前恋人」谓词，用 custom + temporalStatus: former 表达，不硬套 spouse_of。
- 程心-关一帆用 spouse_of + partnerRole: partner、label「伴侣」：原著结尾两人共同生活，未明写婚约，措辞留有余地。
- 罗辑与汪淼同处危机纪元却几乎无直接交往，closeness 1，经史强与叶文洁两条桥接——演示「同一时代的人未必在同一张关系网里」。

## 五、圈层与命名口径

九个圈层对应五条主线加三个计划：面壁计划、行星防御理事会、舰队国际、红岸基地、黄金时代亲属圈、黄金时代旧识、阶梯计划、威慑纪元·星环、罗辑的小家庭。圈层与人物 org 用原著直名（与红楼梦、魔法学院等世界库一致），`identities.platform` 按项目惯例加「（模拟）」后缀（面壁计划（模拟）、阶梯计划（模拟）等）。圈层允许交叠（萨伊兼在行星防御理事会与阶梯计划，程心兼在阶梯与星环），每个人物至少归属一个圈层；人物 key 用小写拼音，多音节分隔用连字符（如 `jiaer-ning`）。

## 七、出处

事件先后与纪年名称主要依据：

- 三体 Wiki《地球往事编年史》：红岸 1971 年发射与 1979 年回信、面壁计划危机纪元 3 年启动、末日之战与威慑建立 205/208 年、执剑人交接（在任 54 年）。
- 百度百科「危机纪元」「伽尔宁」「章北海」条目：危机纪元 2007–2214；伽尔宁为 PDC 轮值主席；「黑暗战役」中「自然选择」号全员罹难、章北海遗言「没关系的，都一样」。
- 三体系列时间线站（earth.three-body.org）：广播纪元 2272–2332、掩体纪元 2333–2400 的区间参考。
- 三体 Wiki「程心」「萨伊」条目：大学时期被云天明暗恋并获赠 DX3906、阶梯计划危机纪元 8 年发射、威慑纪元 62 年接任执剑人、星环城事件与二维化逃离、蓝星重逢关一帆；萨伊宣布面壁计划与群星计划。
- 掩体纪元 11 年星环城事件、66 年太阳系二维化与「星环」号五十二小时航程：依据三体 Wiki「程心」及《死神永生》相关章节梳理。
- 罗辑与庄颜相识（史强依描述在美术学院寻访）、白蓉往事（构想「完美女孩」）：原著《黑暗森林》相关章节。

生日、exact 小时级时刻之外的公历数字均为本库演示映射，不当作原著事实。
