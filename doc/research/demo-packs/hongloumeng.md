# 世界剧场 · 红楼梦演示库设计说明

对应数据文件 `src/lib/demo-packs/world/hongloumeng.ts`，契约测试 `hongloumeng.test.ts`。
本库回答的问题是：一张以贾宝玉为原点的宗族亲缘网，能否让称谓推导、堂表之别、庶出与妾室这些亲属语义在演示里各就各位。

## 一、范围与口径

- 取材《红楼梦》前八十回。人物 35 人，关系 61 条，事件 15 个，提醒 4 条，圈层 4 个。
- 原著自称「朝代年纪，地舆邦国，失落无考」（第一回）。事件 `date` 统一映射到 1720 年代公历，只保证先后排序，不当作史实；原文时间说法保留在 `dateText`（如「正月十五上元夜」「三月中浣」）。
- 亲密度（closeness 1-5）与提醒均为宝玉视角的演示设定；联系方式的口径是 `demo-<key>@example.invalid`，无个人联系方式的角色（仆婢、宫闱、乡下、已故）留空。
- 已故人物（贾敏、林如海、秦可卿、晴雯）保留档案以维系亲属链与剧情，措辞从简，只在 note 里点明回目。

## 二、亲属结构（本库灵魂）

### 父系主干

- 贾母 → 贾政 / 贾赦 / 贾敏（parent_of，第二回冷子兴演说）；贾母 → 宝玉、黛玉（grandparent_of，祖母 / 外祖母）。
- 贾政 → 宝玉、元春、探春、贾环（parent_of）。探春、贾环为赵姨娘所出（第二回），宝玉与二人用 half_sibling_of + sharedParentRole: father。
- 迎春是贾赦庶出之女，生母为贾赦之妾、早亡（第七十三回邢夫人语；第二回各本异文，从脂本口径）。父女关系保留 parent_of，生母不入库——宁少勿错。
- 惜春是宁府贾珍胞妹（第二回），用 sibling_of 表达；她与宝玉并非一级堂亲，不再硬套 cousin。
- 宁荣两府同宗：贾珍、贾芸对宝玉用 clan_of（lineage: clan）。

### 婚姻与妾室

- 正妻：贾政-王夫人、贾琏-王熙凤、林如海-贾敏、（已结束）贾蓉-秦可卿。
- 妾室统一用 spouse_of + qualifiers.partnerRole: "concubine"：赵姨娘→贾政、平儿→贾琏（第六十五回兴儿语）。方向从妾出发，保证契约测试的性别一致性校验通过。

### 堂表之别（cousinBranch 口径）

`cousinBranch` 是 from 端视角的分支，`inverseCousinBranch` 是 to 端视角：

| 关系 | cousinBranch | inverseCousinBranch | 依据 |
| --- | --- | --- | --- |
| 宝玉 → 黛玉 | paternal_aunt（姑表妹） | maternal_uncle（舅表哥） | 黛玉之母贾敏是贾政之妹（第二回） |
| 宝玉 → 宝钗 | maternal_aunt（姨表姐） | maternal_aunt（姨表弟） | 薛姨妈是王夫人胞妹（第四回） |
| 宝玉 → 薛蟠 | maternal_aunt | maternal_aunt | 同上 |
| 宝玉 → 王熙凤 | maternal_uncle（舅表姐） | paternal_aunt（姑表弟） | 凤姐之父是王夫人之兄（第二回「内侄女」） |
| 贾琏 → 宝玉 | paternal_uncle（堂弟） | paternal_uncle（堂兄） | 赦、政两房之子 |
| 宝玉 → 迎春 | paternal_uncle（堂姐） | paternal_uncle（堂弟） | 迎春是贾赦之女 |
| 宝玉 → 湘云 | unspecified | unspecified | 贾母侄孙女，隔代表亲，原著兄妹相称 |

黛玉与宝钗无血缘，第四十五回「金兰契互剖金兰语」，用 friend_of 而非 cousin。

### 仆婢与外围

- 袭人、晴雯（伏侍宝玉），鸳鸯（贾母），紫鹃（黛玉），平儿、小红（凤姐）用 reports_to；怡红院旧同僚（袭人-晴雯、袭人-小红）用 colleague_of。不套亲属谓词。
- 外围一跳：刘姥姥（王家常客）、贾芸（远房子弟）、北静王、蒋玉菡、甄宝玉、贾雨村，各自连回主网，撑起「引荐路径」的演示。
- 湘云是贾母的侄孙女，词表里没有「姑祖母」谓词，用 knows + note 说明，避免错用 uncle_aunt_of。

## 三、八项契约特性的落点

1. 待确认关系：小红 → 贾芸 knows（pending），第二十六、二十七回坠儿传帕，情愫未明；另配贾芸 has_crush_on 小红。
2. 已结束关系：秦可卿 → 贾蓉 spouse_of，validity.status = "ended"，note 写明「这段婚姻随她早逝而止」。
3. 身份史：大观园诗社别号（第三十七回）——宝玉「怡红公子」、黛玉「潇湘妃子」、宝钗「蘅芜君」、探春「蕉下客」、湘云「枕霞旧友」。
4. 同名消歧：贾宝玉与甄宝玉同名同貌（第二回、第五十六回），甄宝玉档案另配「梦中相识」的 metAt。
5. 联系方式有无：14 人留空（仆婢、贾母由鸳鸯代管、元春在宫、刘姥姥、甄宝玉等）。
6. 生日覆盖：19/35（≥半数），canon 9 个 + 演示设定 10 个（见下节）。
7. 时间精度：省亲用 range +「正月十五上元夜」；诗社、挨打、游园等用 month + dateText；宝钗生日用 day +「正月廿一」。
8. 提醒：4 条，due 全部落在 2026-09-20 ~ 2026-10-15（回帖北静王、陪贾母过中秋、给黛玉送时新果品、诗社社课备题）。

## 七、出处

- 原文回目依据通行本（庚辰本为底本的人文学社版系统），关键回目：第二、三、四、六、十五回，第二十二至二十八回，第三十三、三十七至四十一、四十三、四十六回，第五十六、五十七回，第六十二、七十、七十一、七十三、七十四、七十七至七十八回。
- [维基文库《红楼梦》](https://zh.wikisource.org/wiki/紅樓夢)：第六十二回、第七十一回原文。
- [维基百科《红楼梦年谱》](https://zh.wikipedia.org/wiki/紅樓夢年譜)：生日与事件系年参考。
- 凤姐生日九月初二（第四十三回）、探春生日三月初二（第六十二回、第七十回）：红学讨论多篇交叉核对，如知乎专栏《红楼梦》第六十二回、第七十回详解。
- 薛蟠生日五月初三（第二十六回）：另见澎湃新闻《「明儿」是五月初三吗》对口语「明儿」的辨析。
