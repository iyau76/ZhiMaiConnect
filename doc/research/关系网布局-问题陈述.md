## 1. 产品与硬约束

知脉 Connect 是一个本地优先的个人关系秘书：React 19 + TanStack Start，人物关系网是手写 SVG，数据全部在浏览器 IndexedDB 里，没有云端。

关系图画布上有四种模式，共用同一套几何：

| 模式 | 分组来源 |
| --- | --- |
| 不分组 | 无 |
| 按圈层 | `collections` 里 `kind = relationship_circle` 的集合 |
| 按拓扑社区 | 由关系边现算的连通社区（投影，可丢弃） |
| 家族树 | 亲属关系专用布局（另一套算法，不在本文范围） |

会影响方案的产品约束，请当成硬性条件：

1. **不做社会价值排行。** 产品原则是"分数只回答这次该找谁"，不允许把人按亲密度/重要性在图上排成等级。
2. **推断不当事实。** 圈层成员关系必须有用户确认来源；`membership.source = computed` 的成员不入图，`kind = context` 的集合只做筛选，不参与分组。
3. **确定性。** 同一份档案必须画出完全一样的图：e2e 会点"第一个节点"、比较父子节点的 y 坐标。
4. **图既要看也要操作。** 点选聚焦、拖动节点（拖过的坐标会被记住）、双击开人物卡、连线建关系、全屏、滚轮与双指缩放（0.4×–4×）。
5. **本地算。** 没有服务端，布局在主线程跑；已有 e2e 用 50 人 80 关系做交互冒烟。

## 2. 数据模型（唯一真相）

- `persons` / `relations` / `collections(kind: relationship_circle | context)` / `collection_memberships(personId, collectionId, source: manual | ai | computed)`
- 一个人属于多个圈层是常态，不是例外。
- 圈层是**集合**语义，不是分区语义：A 和 B 可以相交，交集里可以有人。

## 3. 现在的实现

### 3.1 分组：按"成员身份组合"做互斥分区

`buildCircleLayoutProjection` 把一个人所属的圈层 id 排序后拼成 key：

```ts
const key = collectionIds.length ? `circles:${collectionIds.join("\u0000")}` : "circles:none";
// 标签 = 圈层名用 " / " 连接
label: personCollections.map((c) => c.name).join(" / "),
```

结果：`{红岸基地}`、`{黄金时代亲属圈}`、`{红岸基地 + 黄金时代亲属圈}` 是三个互斥的簇，几何上永远不会相交。源码注释里写明了这是有意的取舍：

> A person in several circles gets a stable composite group, so no membership is silently discarded merely because a graph node can occupy only one position.

代价是：N 个圈层最多产生 2^N − 1 个簇；交集被改名成了一个并不存在的圈层。

### 3.2 几何：环套环

- **组内**：≤24 人排在一个正圆上，半径 `MIN_EDGE / (2·sin(π/count))`，`MIN_EDGE = 150`；>24 人改成每 170 单位一层的同心环（中心永远空）。
- **组间**：每个簇自成一个盘，簇心均匀分布在一个大环上，半径
  `max(maxR × 1.6, (maxR + 30) / sin(π / k))` —— 这个公式的意思是"k 个互不重叠的圆要放在一个环上，环必须多大"。
- 画布边长由最外半径推出：`size ≈ 2 × (ringRadius + maxR + 56)`，viewBox 是正方形 `0 0 size size`。

也就是说：画布尺寸由**簇数**和**簇半径**共同决定，而簇数由组合数决定。

### 3.3 渲染：所有东西画在同一个 transform 里

- 容器高度：`h-[clamp(20rem,46vh,32rem)]`（典型窗口下约 430px），宽度占满，约 1050px。
- viewBox 是正方形，`preserveAspectRatio="xMidYMid meet"` → 实际显示时按高度缩放，左右两侧各留一大块空白。
- 节点圆半径 16（选中 19）；名字画在节点下方 34 单位处，字号 `12 × labelScale`（labelScale 可在 0.8–1.6 之间调）；边标签 11；簇标题 11。
- 这些都在 `<g transform="translate(tx ty) scale(s)">` 内部，所以：

  **屏幕上的真实字号 = 12 × (容器高度 ÷ size) × scale**

- 工具栏的「适应」只是把 scale 归 1（不是 fit-to-content）；缩放范围 0.4×–4×。

### 4.2 尺度崩坏

| 指标 | 实测值 |
| --- | --- |
| 25 人 / 15 簇时的 `size` | 2237 |
| 容器高 430px 时，12px 标签的实际渲染大小 | **2.3px** |
| 缩放拉满（4×）后的字号 | 约 9px；叠加 A+ 上限（×1.6）也只有 14.7px |
| 单人簇占用的包络半径 | 52（组件里还会抬到 86），内部只有一个半径 16 的点 |
| 双人簇 / 四人簇的包络半径 | 142 / 158 |
| 正方形 viewBox 塞进 1050×430 容器 | 左右各浪费约 310px |

作为对照：同样 25 人**不分组**时 `size = 1168`，12px 标签能渲染成 4.42px —— 布局膨胀才是主要杀手（`size` 从 1168 涨到 2237），字号写在图形坐标系里是第二个杀手。

一个反直觉的推论：**单靠紧凑打包救不回来。** 把这 15 个簇盘按半径从大到小密排到六边形格子上，包围盒最好也只能压到 935（现状是 2237，差了 2.4 倍），对应字号 5.5px —— 仍然读不了。所以字号必须脱离图形坐标系；同时"每个成员组合都要独占一个盘"这件事也得先处理掉，否则盘的数量和尺寸本身就决定了画布下限。

### 4.3 用户的体感

一整个大环，15 个簇贴在环上，中心大片空白，环上的名字小到看不清。

"放大也看不清"是可解释的：字号在图形坐标系里，所以屏幕上能拿到的最大字号 = 12 × (430 ÷ 2237) × 4（缩放上限） × 1.6（A+ 上限）≈ 14.7px，而且只有在 4× 缩放时才能达到，那时画布上只剩一小块视野，读几个名字就得来回平移。默认视图下则是 2.3px，等于不可用。

## 5. 两个待解决的困难（用户原话）

> 一是人物过多的时候，所有人都排成大圆圈，这样中心就有很多空白，而边上的字太小，放大了也看不清。第二个问题是，一个人可以属于多个圈层，而现在的规则很可能是很蠢的，如图所示，它不允许韦恩图相交。

需要补充的是：这两个问题互相纠缠。分组方式决定画布尺寸，画布尺寸决定屏幕字号，屏幕字号决定默认视图能显示多少标签。只改其中一处都会露馅。

## 6. 已经否掉或已知有代价的路线

| 路线 | 结论 | 原因 |
| --- | --- | --- |
| 真 Venn / Euler 图布局（把每个交集区域都解出来） | 不建议 | ≤3 个集合勉强可行；集合数一多既 NP 难又没法看；用户的圈层数量没有上限 |
| 同心环按亲密度/重要性分层 | 与产品冲突 | 等于在图上画社会地位排行；本项目明确禁止 |
| 力导向（斥力 + 弹簧） | 待评估 | 不确定性高、难以写稳定的 e2e、大图占主线程；用户提过"加物理斥力"这个方向 |
| 组合键分区（现状） | 保留中 | 保证不丢成员关系，代价是不能相交 + 组合爆炸 |

## 7. 任何方案都要满足的验收条件

1. 确定性：同一份输入画出同一张图，稳定到像素（现有 e2e 依赖点击第一个节点的位置）。
2. 不静默丢成员关系：必须能看出每个人属于哪些圈层。
3. 25 人 / 9 圈层下，"哪些圈层相交、谁在交集里"要一眼可见。
4. 常见人名（2–4 字）在默认视图可读，或者有一套明确的标签分级显示规则。
5. 现有交互不回退：点选聚焦、拖动节点、建关系、全屏、缩放、家族树、拓扑社区。
6. 几何层是纯函数、可单测、不碰档案；200 人规模布局计算 < 50ms。
7. 不引入看不懂的随机感（图必须稳定，不能每次刷新换一个形状）。

## 附录 B：当前几何实现（重构版，语义与 main 的内联实现一致）

```ts
export const DEFAULT_GRAPH_MIN_EDGE = 150;

/** 环形排布时，为了让相邻两点至少隔开 minEdge 所需的半径 */
export function ringRadiusFor(count: number, minEdge: number) {
  if (count <= 1) return 0;
  return Math.max(minEdge * 0.6, minEdge / (2 * Math.sin(Math.PI / count)));
}

/** 人多时不再把圆周越撑越大，改成多层同心环。 */
export function layeredRingPoints(count: number, minEdge = DEFAULT_GRAPH_MIN_EDGE) {
  if (count <= 24) {
    const radius = ringRadiusFor(count, minEdge);
    return {
      radius,
      points: Array.from({ length: count }, (_, index) => {
        const angle = (index / Math.max(count, 1)) * Math.PI * 2 - Math.PI / 2;
        return count === 1
          ? { x: 0, y: 0 }
          : { x: radius * Math.cos(angle), y: radius * Math.sin(angle) };
      }),
    };
  }
  const ringStep = 170;
  const points: Array<{ x: number; y: number }> = [];
  let ring = 1;
  while (points.length < count) {
    const radius = ring * ringStep;
    const capacity = Math.max(8, Math.floor((Math.PI * 2 * radius) / minEdge));
    const take = Math.min(capacity, count - points.length);
    for (let index = 0; index < take; index += 1) {
      const angle = (index / take) * Math.PI * 2 - Math.PI / 2 + (ring % 2 ? 0 : Math.PI / take);
      points.push({ x: radius * Math.cos(angle), y: radius * Math.sin(angle) });
    }
    ring += 1;
  }
  return { radius: (ring - 1) * ringStep, points };
}

export function layoutRelationGraph(
  nodes: Array<{ id: string; groupKey?: string }>,
  groups: Array<{ key: string; label: string }> = [],
  minEdge = DEFAULT_GRAPH_MIN_EDGE,
) {
  const grouped = groups.length > 0 && nodes.some((node) => (node.groupKey ?? "") !== "");
  if (!grouped) {
    const layout = layeredRingPoints(nodes.length, minEdge);
    const size = 2 * (layout.radius + 74);
    const center = size / 2;
    return {
      size,
      nodes: nodes.map((node, index) => {
        const point = layout.points[index] ?? { x: 0, y: 0 };
        return { id: node.id, groupKey: "", x: center + point.x, y: center + point.y };
      }),
      clusters: [],
    };
  }

  const membersByKey = new Map<string, typeof nodes>();
  for (const node of nodes) {
    const key = node.groupKey ?? "";
    membersByKey.set(key, [...(membersByKey.get(key) ?? []), node]);
  }
  const buckets = groups
    .map((group) => ({ ...group, members: membersByKey.get(group.key) ?? [] }))
    .filter((bucket) => bucket.members.length > 0);
  const inner = buckets.map((bucket) => layeredRingPoints(bucket.members.length, minEdge));
  const maxR = Math.max(...inner.map((layout) => layout.radius + 52), 120);
  // 多个圈层时，各簇均匀分布在一个更大的环上，彼此不重叠
  const ringRadius =
    buckets.length > 1 ? Math.max(maxR * 1.6, (maxR + 30) / Math.sin(Math.PI / buckets.length)) : 0;
  const size = 2 * (ringRadius + maxR + 56);
  const center = size / 2;

  const placements: Array<{ id: string; groupKey: string; x: number; y: number }> = [];
  const clusters: Array<{ key: string; label: string; x: number; y: number; r: number }> = [];
  buckets.forEach((bucket, bucketIndex) => {
    const angle = (bucketIndex / buckets.length) * Math.PI * 2 - Math.PI / 2;
    const cx = center + ringRadius * Math.cos(angle);
    const cy = center + ringRadius * Math.sin(angle);
    clusters.push({
      key: bucket.key,
      label: bucket.label,
      x: cx,
      y: cy,
      r: inner[bucketIndex].radius + 52,
    });
    bucket.members.forEach((node, index) => {
      const point = inner[bucketIndex].points[index] ?? { x: 0, y: 0 };
      placements.push({ id: node.id, groupKey: bucket.key, x: cx + point.x, y: cy + point.y });
    });
  });

  return { size, nodes: placements, clusters };
}
```

组件在此基础上做了两件事：把簇的圆心和半径按成员的实际落点重算（`cluster.r = Math.max(86, …)`），以及覆盖用户拖动过的节点坐标。簇的外形是一段 14 个采样点、带种子抖动的闭合 Catmull-Rom 曲线（`relations-panel.tsx` 里的 `blob()`），形状会跟着成员位置流动。

```ts
      Array.from({ length: size }, (_, i) => ({ id: `n${group}-${i}`, groupKey: `c${group}` })),
    );
    const groups = sizes.map((_, i) => ({ key: `c${i}`, label: `圈层${i + 1}` }));
    const grouped = layoutRelationGraph(nodes, groups);
    console.log("分组 size=", Math.round(grouped.size), "屏幕上12px字=", px(grouped.size));
    console.log("簇半径=", [...new Set(grouped.clusters.map((c) => Math.round(c.r)))].join(","));

    const plain = layoutRelationGraph(
      Array.from({ length: 25 }, (_, i) => ({ id: `p${i}`, groupKey: "" })),
    );
    console.log("不分组 size=", Math.round(plain.size), "屏幕上12px字=", px(plain.size));
    expect(grouped.size).toBeGreaterThan(0);
  });
});
```
