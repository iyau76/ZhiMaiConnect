## 1. 背景结论与计划边界

### 1.1 采用的产品定义

- [x] 统一产品定位为：**本地优先、证据可追溯的人际关系记忆与行动助手**。
- [x] 核心用户任务固定为三类：跨平台身份记忆、关系情境记忆、关系行动支持。
- [x] 首批目标用户聚焦关系密集型人群：学生组织者、社群负责人、研究人员、招聘/销售、自由职业者、校友工作者。
- [x] 核心差异化固定为四项：身份历史与可逆归并、证据可追溯、可解释行动推荐、低摩擦隐私优先采集。
- [x] 将“生日祝福生成”定位为入口能力，而非主要创新点。
- [x] 将二维关系图定位为检索与解释界面，而非单纯视觉展示。

### 1.2 明确不做

- [x] 不登录、抓取或逆向读取个人微信、QQ、小红书。
- [x] 不宣称已有个人微信好友、聊天、朋友圈或分组管理接口。
- [x] 不自动刷朋友圈、修改好友分组、修改备注或群发消息。
- [x] 不在未经逐条确认时自动写入 AI 推断事实或对外发送内容。
- [x] 原材料不写入正式人物档案；原始录音不落盘，图片只保留提取文字，未提交文字/文件提取内容仅在本浏览器暂存、24 小时过期并可一键清除。
- [x] 不把 3D 全局关系图作为主交互。
- [x] 不依赖早期调研中无法核验的 Murmur、Affinity 项目。
- [x] 不在竞赛初评前启动 Android/iOS 双端、邮箱同步或复杂云同步。

### 1.3 资料结论优先级

- [x] `人际关系agent.pdf` 仅作为早期思路记录；其中错误仓库、许可证和平台接口结论不得进入答辩材料。
