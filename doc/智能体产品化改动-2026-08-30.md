# 知脉 Connect 智能体产品化改动

> 日期：2026-08-30  
> 范围：在保留现有本地优先、关系核心与探案功能框架的基础上，补齐智能体产品叙事与行动规划能力。

## 一、智能体过程面板

- `src/components/reasoning-disclosure.tsx`：从单行状态条升级为可展开面板，按“准备 / 分析 / 工具 / 校验 / 完成 / 错误”分阶段展示，并统计工具调用与校验次数。
- 组件新增 `events` 属性，保留 `history` 兼容。
- 录入页、问答页、引荐页均改为传入结构化 trace（`events`）。
- `src/styles.css`：新增 `.reasoning-disclosure-body` 样式。

## 二、行动规划智能体与计划页

- 新增 `src/lib/planning-agent.ts`：多轮工具调用智能体，把用户目标拆成 3-8 条可执行行动项；`personIds` 必须来自本机档案，输出经校验后写入任务库。
- `src/components/plan-board.tsx`：改造为“行动计划”看板，新增目标输入与“智能体拆解任务”按钮、规划轨迹面板；保留手动补录。
- `src/routes/index.tsx`：导航新增“计划”入口（`ClipboardList` 图标），并把“AI 助理”改名为“智能体”。

## 三、智能体叙事与文案

- 录入按钮：`AI 整理成档案` → `智能体整理成档案`。
- 问答模块：`问一问` → `问答智能体`。
- 引荐模块：`这事该拜托谁` → `引荐智能体`。
- `src/components/models-panel.tsx`、`reminders-panel.tsx`、`preflight-panel.tsx` 同步更新标题与提示。
- 当前工程的档案写入通道为 `src/lib/archive-mutation-plan.ts`，人物与关系修改的来源标注统一改为“智能体提议，经用户批准”。
- `src/lib/i18n.ts` 增加中英条目。

## 四、第一层提示词优化

以下 8 个文件均增加 `prompt v2 · 2026-08-30` 版本注释、示例与更严格的约束：

| 文件 | 改动 |
| --- | --- |
| `src/components/intake-panel.tsx` | 录入基础提示词增加“材料 → 标准 JSON”示例，收紧未提及内容不得填写。 |
| `src/lib/intake-agent.ts` | 固定“先检索 → 核对 ID → 再暂存”顺序，补充最终草稿示例。 |
| `src/lib/assistant-agent.ts` | 补充工具调用与最终回答示例，强化“未命中 ≠ 不存在”和提案写库边界。 |
| `src/lib/recommendation-agent.ts` | 补充最终 JSON 示例，把“本地锁定排序不可改动”写成可对照硬约束。 |
| `src/lib/planning-agent.ts` | 补充“目标 → 任务 JSON”示例，强调 `personIds` 必须来自档案。 |
| `src/lib/recommendation.ts` | 只允许引用候选卡里的理由、证据和风险，禁止新增人物或编造理由。 |
| `src/lib/personal.ts` | 祝福/礼物提示词固定“资料不足”句式，禁止补写未知喜好。 |
| `src/lib/fuzzy-date.ts` | 模糊日期提示词增加“去年夏天”示例，统一 range 输出格式。 |
