# PWA 首版实现与验证

日期：2026-09-06。分支：`feature/stage4-local-pwa-20260905`，基于 `d132949`。本轮完成首版实现与自动化回归；尚未提交、合并、推送或部署。阶段 4 的手机实机验收仍待完成。

## 本轮交付

- 安装入口：Manifest、品牌图标、主屏幕快捷入口、设置页安装指引与离线准备状态。
- 离线使用：生产构建缓存应用页面与静态资源；断网后可以重新打开、记录文字、查看资料及使用已有本地批准流程。模型请求不进入缓存。
- 手机导航：底部提供今天、录入、人物关系、提醒和更多入口；适配屏幕安全区，输入框使用至少 16px 字号。录入的文件、拍照、录音与整理按钮触摸高度至少 44px。
- 录入首屏：帮助说明按需展开，手机上的长篇示例收起，输入框保留一句示例。390 × 844 视口内四个主要录入按钮均位于底部导航上方。
- 本机材料：系统分享、离线文件和离线录音进入同一个 IndexedDB 收件箱。恢复网络不触发上传，由用户选择读取；成功追加文字后移除对应条目。
- 草稿保留：取消 24 小时过期，追加材料时一起保存来源 ID，避免交接中断后重复追加。内容未变化的旧窗口在关闭时不再覆盖新窗口已经保存的草稿。
- 版本更新：新版本下载完成后等待旧窗口全部关闭，随后启用。不会主动刷新正在使用的窗口。
- 资料边界：免登录、不接入清小搭、不创建云端人物数据库或同步通道；正式资料仍沿用原有 `archive@2`、提案、批准和撤销结构。

生产预览还发现了原有 `agent-run-owner` 在模块顶层调用 `crypto.randomUUID()` 的问题；改为访问时生成，使 Worker 的 SSR 模块加载可以正常完成，并增加相应单测。

## 本机体验

本轮启动的生产预览地址为 `http://127.0.0.1:4180/?view=settings`。该地址与原开发端口及云端地址使用不同的本地存储；首次打开为空库，适合使用合成演示数据体验。

后续可以这样重新启动：

```sh
npm run build
npx wrangler dev --config .output/server/wrangler.json --ip 127.0.0.1 --port 4180
```

进入设置，等到“离线资源已就绪”，再断网刷新、切换页面、填写录入材料。开发模式 `npm run dev` 不注册 Service Worker。

## 实机待验收

1. Android Chrome：安装到主屏幕，关闭后断网重开；从系统分享面板发送文字和图片；使用相机、麦克风后检查材料保存。
2. iPhone：添加到主屏幕，检查独立窗口、软键盘、安全区、相机和麦克风；系统分享接收能力单独确认。
3. 在两个真实版本之间验证更新提示、关闭全部窗口后的切换和原有资料保留。
4. 在日常使用网络验证首次打开与模型请求。PWA 不解决 `workers.dev` 的国内首次访问困难，站点访问方案需另行决策。

手机上的 localhost 指向手机自身，不能使用电脑的上述地址安装。真机测试需要可达的 HTTPS 部署或受信任的本地 HTTPS 环境；本轮没有变更云端版本。

当前不提供关闭应用后的定时通知或多设备同步。浏览器后台可能被操作系统冻结；AI 仍使用已有断点恢复。原始文件和未提交草稿不在完整备份范围内，浏览器存储持久化申请也不能替代备份。

现行设计见 [PWA 与本机材料](../../architecture/PWA与本机材料.md)。
